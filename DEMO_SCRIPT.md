## 🎤 Presentation Tips

### Energy & Pacing
- **Start strong**: Hook them in the first 5 seconds
- **Vary your pace**: Slow down for key points, speed up for transitions
- **Show enthusiasm**: You built something amazing - let it show!
- **Use pauses**: After showing a transaction, pause 1-2 seconds to let it sink in

### What to Emphasize
1. **"Real-time LLM decisions"** - This is your differentiator
2. **"Emergent behavior"** - Not scripted, genuinely unpredictable
3. **"Shadow economy"** - The emotional layer that makes it special
4. **"Zero cost"** - Shows technical skill and resourcefulness

### Handling Issues
- **No drama events yet?** "The shadow economy needs time to develop. Betrayals are rare but impactful. Right now we're in the calm before the storm - agents are building trust and testing each other."
- **Shadow stats all at zero?** "Perfect - this shows the economy is stable right now. But watch what happens when the first betrayal occurs - these numbers will spike."
- **API rate limit?** "We have fallback logic - agents make safe decisions when the LLM is rate-limited. The economy keeps running."
- **Slow transaction?** "Each decision takes 1-3 seconds as Gemini analyzes the full state - personality, wallet, relationships, and context."

### Body Language (if presenting live)
- Point to specific elements on screen
- Use hand gestures to show flow (agent → decision → action → consequence)
- Make eye contact with judges/camera
- Smile when showing cool features (revenge, betrayals)

## 🎥 Recording Tips (if making video)

### Setup
- **Screen resolution**: 1920x1080 minimum
- **Recording software**: OBS Studio (free) or Loom
- **Microphone**: Clear audio is critical
- **Lighting**: Face should be well-lit if showing yourself

### Editing
- Add text overlays for key terms: "LLM-Powered", "Emergent Behavior", "Shadow Economy"
- Zoom in on specific UI elements when explaining them
- Add subtle background music (low volume, non-distracting)
- Include captions for accessibility

### Structure
1. **Intro screen** (3 sec): "SHADOWNET" title
2. **Live demo** (1:50): Follow script above
3. **Outro screen** (7 sec): Links to demo, GitHub, contact
